# M04 模型中心与凭证管理 模块设计 v1.0

> **职责**：客户端的模型接入与凭证底座——三种提供商接入与能力分级/回退、首次引导流、Token 计量与熔断对接、凭证本机加密、CredentialBroker 与不透明 CredentialHandle、login→凭证落库、认证会话隔离存储/即焚/可撤销、凭证外传一票否决对接。
>
> **上游依据**：`01-产品文档.md` v14.2 §5（5.1/5.2）、§11、§16.3；`02-技术架构.md` v8.2 §6.5、§11.2（另：§4.3 认证会话、§8.3/§8.4 ModelRouter、附录 D 错误码）。
>
> **状态**：起草（2026-10-14）。


## 1. 职责与边界

| IN（本模块负责） | OUT（不属于本模块） |
|---|---|
| 模型提供商接入：内置提供商 / 聚合平台 / 自定义三种（PRD §5.1） | 模型调用出网判定与端点白名单执行（M05 策略引擎） |
| 能力分级 fast/reasoning/vision 解析与回退（未配置回退 fast 并提示） | 装配助手/草稿生成会话编排（M08，熔断消费方之一） |
| 首次模型引导流（含境外模型固定提示语） | login 交互控件与流程编排（M16/M03） |
| Token 计量本地账本 + 每会话熔断配置（对接 ModelRouter） | 认证会话的业务流程（M09 本机认证器） |
| 凭证本机加密（safeStorage；Windows DPAPI / macOS Keychain） | 凭证外传 lint 执行与上架裁决（M07/M10） |
| CredentialBroker：Handle 发放/注入/刷新/撤销 | 详情页 Token 成本区间（M09 认证实测产生） |
| login→凭证落库：Cookie 主路径 + token/localStorage 站点适配器（架构 §6.5） | 首次运行授权页整页宿主与渲染（M03） |
| 认证会话隔离存储 / 即焚 / 撤销原语；凭证管理与模型设置 UI | CDP 采集底层实现（M06 执行，契约在此定义） |

**核心不变量**：
1. 凭证明文只存在于 safeStorage 解密后的进程内存；任何表、日志、上报、崩溃转储不含明文或可解密材料；**服务端不存储用户凭证，服务端凭证接口面为空**（红线 2，PRD §16.3）；
2. CredentialHandle 不透明：组件/积木代码不可由 Handle 反推凭证内容，凭证仅经 Broker 的受控通道注入；
3. 认证会话与用户日常凭证隔离存储，跑完即焚、可撤销（架构 §11.2）；
4. **用户侧 Token 完全用户自付**（红线 1）：本模块不提供任何平台经手、代付、垫付的调用路径。

## 3. 关键流程

### 3.1 首次引导流

```text
首启检测 model_providers 为空（创作者与买家同一路径，PRD §5.1）
  → 引导页：三种接入选择
      内置提供商 / 聚合平台 / 自定义提供商（base_url + Key）
  → 固定提示语（原文引用 PRD §5.1，**引导页无条件固定展示**——不依赖用户是否选择境外服务，不可省略、不可折叠）：
      "选择境外模型服务时，您的输入与输出将传输至相应境外服务商。"
  → Key 连通性测试 → safeStorage 加密落库（key_ref 引用，不落明文）→ tier 以配置为准（未配置按 §3.2 回退）
```

内置提供商目录由平台签名下发（目录内容与更新机制 TBD（模块细化时定）），客户端不可本地增删内置项。

### 3.2 能力分级与回退

- 积木权限 `ai:fast / ai:reasoning / ai:vision` → ModelCenter 解析用户当前配置；
- 请求 tier 未配置 → **回退 fast 并提示**（PRD §5.1）：产生提示事件入运行日志与通知中心，事件附 provider/model 供调用方展示；
- fast 亦未配置 → `credential_missing`（→ waiting_user，引导完成模型配置；附录 D）。**归因注记**：本场景复用该错误码，env_class=account 计 user-side；承载交互为**表单族（模型配置引导）**，与站点凭证缺失（浏览器族重登）通过 M16 §3.4 的承载映射区分，统计侧按 env_class 归因不混淆。

### 3.3 login → 凭证落库（架构 §6.5）

```text
浏览器族 login 交互完成（M16 协议）
  → 本模块经 CDP 捕获登录态（采集器由 M06 实现，采集契约在此定义）：
      · Cookie（主路径）
      · token / localStorage 类登录态：按站点适配器声明的采集字段
        （覆盖 JWT 型站点）
  → safeStorage 加密落库 credentials（关联 credential_id 与站点）
  → CredentialBroker 发放不透明 CredentialHandle
  → 后续运行免登录；有效期与刷新由 Broker 管理
```

- 站点适配器（Cookie 之外需采集的字段声明）随平台签名配置分发（载体 TBD（模块细化时定））；未声明适配器的站点仅走 Cookie 主路径；
- 首次运行授权页（PRD §11）："将使用您在 XX 的登录态执行：浏览抓取 / 表单提交 / 对外发布"操作清单与账号风险告知一行的凭证侧数据由本模块提供，页面宿主归 M03。

### 3.4 Handle 生命周期与撤销

| 阶段 | 行为 |
|---|---|
| 发放 | 运行会话启动时按 grants 中的 credential 权限发放；Handle ↔ credential_id 映射仅存内存与加密库 |
| 注入 | 仅两条受控通道：浏览器会话装载（M06 按 Handle 注入登录态）；模型调用装载用户 Key（ModelRouter）。组件进程永不见明文 |
| 刷新 | 有效期与刷新由 Broker 管理；运行失败归因 auth_expired 且 env_class=account（user-side）→ 提示重新 login |
| 撤销 | 凭证管理 UI 一键撤销：Handle 全部失效、加密条目删除（无任何可恢复副本）；后续引用该凭证的运行 → `credential_revoked` → waiting_user（重新登录引导） |

### 3.5 认证会话（C1）隔离

- M09 本机认证器在创作者**显式授权**后创建认证会话：写入 `auth_sessions` 隔离区（与 `credentials` 分表分区、独立加密上下文）；
- 认证会话仅用于认证过程，日常运行不读取；**跑完即焚**——认证报告上传完成后删除条目（磁盘残留扫描为验收项）；
- 可随时撤销，撤销即时生效并中止进行中的认证运行。

### 3.6 Token 计量与熔断对接

- ModelRouter 统一记录 provider/model/tokens/cost（架构 §8.4）→ 本模块写 `model_usage` 本地账本并提供查询 UI；
- 每会话 Token/金额硬上限熔断：创作者可配（会话级覆盖）；**默认值随站点变更等级分档**（standard/medium/high/protected）——分档默认值由平台签名配置下发，具体数值 TBD（模块细化时定），本地不可改写；
- 熔断触发 → 该会话模型调用停止；草稿生成循环按 best-so-far 回滚由 M08 执行（架构 §8.3），本模块只提供熔断状态。

### 3.7 凭证外传一票否决的对接（PRD §5.2）

- Handle 形态规范：不透明随机标识，不含站点/用户信息（防枚举猜测）；
- 向 M07 lint 提供判定输入：**凭证句柄出现在网络请求体中 = 一票否决不上架**——静态判定特征集 TBD（模块细化时定）；
- 运行时联动：出口代理 `egress_denied` 安全事件与 CDP 注入异常域名告警（M05 §3.3）中涉及凭证的样本回流本模块标记复核。


## 4. 数据模型

```text
model_providers(
  id, kind,                  # builtin / aggregator / custom
  name, base_url,
  tiers_json,                # fast / reasoning / vision → 模型映射
  key_ref,                   # safeStorage 引用（非明文）
  status, created_at, updated_at
)
credentials(                 # 用户日常凭证
  id, site, kind,            # cookie / token / local_storage（适配器声明）
  payload_enc,               # safeStorage 密文
  status,                    # active / expired / revoked
  created_at, updated_at, last_used_at
)
auth_sessions(               # 认证会话（C1）——与 credentials 分表分区
  id, cert_run_ref, site,
  payload_enc, status,       # active / burned / revoked
  created_at, burned_at
)
model_usage(                 # ModelRouter 计量账本（本地）
  id, session_ref, provider, model,
  tokens_in, tokens_out, cost,
  ts                         # cost 精度随提供商账单口径，展示层换算
)
budget_rules(                # 每会话熔断配置
  id, scope,                 # platform_default（签名只读）/ session_override
  site_tier_defaults_json, tokens_limit, amount_limit   # 分档默认随**站点变更等级**（standard/medium/high/protected）
)
```


## 5. 接口

**Renderer IPC（contextBridge，经 M01）**：
- `providers.list/upsert/test/remove`——Key 输入直交 Main 入 safeStorage，IPC 与 Renderer 层不持久明文；
- `credentials.list/revoke`——仅返回元数据与状态；`usage.query(window)`、`budget.get/set(session)`。

**Sidecar 内部（named pipe + HMAC，走 M05 通道）**：
- `modelcenter.resolveTier(tier) → {provider, model, key}`（含回退结果与提示事件）；
- `broker.issue(session, credential_perm) → handle`；`broker.injectScope(handle) → {channel: browser|model}`（受控通道描述）；
- `broker.revoke(id)`、`broker.burnAuthSession(id)`；
- `ledger.report(usage)`、`budget.check(session) → {allowed, remaining}`。

**事件出口**：`credential_missing / credential_revoked` → M16（waiting_user，凭证配置交互）；`tier_fallback` → 通知中心（M01）。

**服务端接口面**：凭证类为空（服务端不存储、不传输用户凭证——显式声明，红线 2）。

## 7. 验收标准

1. 红线测试：全库/全日志/上报采样/崩溃转储中检索不到凭证明文与可解密材料；服务端无凭证字段存储与接口（代码审查记录在案）；
2. 回退：仅配置 fast 时请求 vision/reasoning → 回退 fast 且产生提示事件；零配置 → `credential_missing` → waiting_user 引导；
3. 落库：login 完成后 Cookie 主路径免登录复跑通过；JWT 型站点按适配器采集 token/localStorage 通过；
4. 不透明：组件进程全程仅见 Handle；由 Handle 反推凭证内容的路径不存在（代码审计 + 用例）；
5. 即焚：认证报告上传后 `auth_sessions` 条目删除，磁盘残留扫描通过；撤销即时中止认证运行；
6. 撤销 UI：撤销后引用该凭证的运行进入 waiting_user（重新登录引导），旧密文无残留；
7. 熔断：会话超限 → 模型调用停止（与 M08 best-so-far 回滚联测）；分档默认值本地不可改写（签名校验失败拒绝生效）；
8. 引导流：引导页**无条件**出现境外模型固定提示语（与 PRD §5.1 原文一致，不依赖用户选择境外服务）；未完成配置前 AI 类运行被引导至配置；
9. lint 对接：网络请求体含凭证句柄的样例组件被 M07 判一票否决（联测记录）。
