## 2. 里程碑详情

### MS-0 端到端验证（第 1-2 周）
- **交付**：浏览器链路验证脚本；站点结构检测最小版；手工积木演示（标准站点搜索→Excel 报告）。
- **验收**：T0.1-T0.3 验收命令输出归档。
- **意义**：验证 TDD §1 选型在真实环境成立；失败则回选型评审。

### MS-1A Spike（第 2-3 周）★
- **交付**：Windows / macOS 双平台出网强制验证报告（四验证点：进程树继承、重定向可达、绕过丢弃、性能 <10% 附加延迟；验证对象为 D-1 已定的防火墙白名单/专用用户机制）。
- **决策 D-1**：**已决策（2026-10-14，05 附录 A.1）**——v1 采用防火墙白名单/专用用户路线，自定义 WFP/PF 过滤器推迟到阶段 5；Spike 由选型转为验证型。
- **风险**：白名单机制验证点不成立时按附录 A.1 回退链处理（先细化规则 → 再评估容器级）；原 No-Go 重估风险已消除。

### MS-1B 轨迹格式冻结（第 3 周）★
- **交付**：`trace/` 格式 v1（M07 §4）+ M02/M06/M08/M09 四方会签记录 + proto 包类型定义。
- **后续变更**：走 minor（触发四方适配评审）。

### MS-1C SDK+lint（第 4 周）
- **交付**：block.yaml v2 校验器、lint 十规则、ComponentError、runtime 外观桩。
- **验收**：每条规则正反用例；合规示例积木通过全链校验。

### MS-1D 录制回放（第 5-6 周）
- **交付**：Recorder（含元素圈选标注）、Replayer local 模式、golden 采集与脱敏、golden_similarity 断言。
- **验收**：3 个种子站点（含 1 高变更）录制→回放 10 次一致；脱敏后无原始值。

### MS-1E 认证流水线（第 5-7 周，与 1D 并行）
- **交付**：调度器（批次礼仪强制）、C2 沙箱执行器、LocalCertifier（设备注册+nonce+签名上报）、抽查重测链路、认证报告 API。
- **验收**：C2（无登录）与 C1（含登录）各完成一个真实积木的 N≥20 认证，live/regression 分列落库。

### MS-1F 种子积木库 + 自制应用（第 6-9 周）
- **交付**：10 场景 20-30 个平台自营积木（全部持 C1/C2 报告）；3-5 个平台组装应用；Creator Center 最小版支撑内部全流程。
- **决策 D-3**：选站清单（法务安全度 × 使用频率，标准/中变更优先）。
- **验收**：每个积木认证报告可查；应用整链验证完成。

### MS-1G 阶段 1 出口（第 9-10 周）★
- **交付**：覆盖率实验报告（30-50 真实需求，判定标准与记录存档）。
- **决策 D-4**：≥60% → 进阶段 2；<60% → 收窄场景集重做种子库（**不进**创作者开放投入）。
- **D-4 判定（2026-10-19，人工）**：**fail**——实测覆盖 1/30=3.3%（门槛 ≥60% 即 18/30），按 A.4 进收窄路径：收窄场景集重做种子库、不进创作者开放投入（维持 PRD §15 结论）。判定依据 = `spikes/evidence/coverage/report.md`（30 判定恰一次冻结）。
- **R2 复判执行（2026-10-23，恰一次判定冻结）**：收窄重做轮（docs/15 T1.70-T1.79）完毕后复判实测**覆盖 3/30=10.0%**（未覆盖归因 capability_missing 14 / needs_genericization 7 / site_not_covered 5 / shape_mismatch 1），报告只呈数据 = `spikes/evidence/coverage_r2/report.md`。**D-4 复判判定待人工**（10.0%<60% 门槛）。
- **D-4 复判判定（2026-10-25，人工）**：**fail（终判）**——R2 实测覆盖 3/30=10.0%（门槛 ≥60% 即 18/30），维持收窄、不进创作者开放投入（维持 PRD §15 结论）；用户裁定**关账往前走、不再起第三轮收窄重做**，MS-1G 按出口未达关账，阶段 1 收口。判定依据 = `spikes/evidence/coverage_r2/report.md`（30 判定恰一次冻结）。

## 3. 度量与节奏

- **每任务**：验收命令输出归档（05 计划 A3），无证据不合并；
- **每日**：各工作组任务卡燃尽；阻塞上报；
- **每周**：里程碑健康检查（gate 指标趋势 + 估算校准）；MS-1A/1B 后各校准一次全局估算；
- **每里程碑**：AI 评审员全量抽查（测试有效性/锚一致性），人类决策点强制到场；
- **指标口径**：全部按 PRD §14 四要素（测量位置/窗口/归因/目标值）执行，埋点任务随 MS-2/MS-3 交付。
