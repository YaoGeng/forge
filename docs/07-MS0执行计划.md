## 2. Review Focus（计划隐含、任务测试未覆盖的失败面；每行已挂归属测试）

1. **站点返回 200 但内容异常**（改版、风控/验证码页、空结果）——脚本不得静默产出空报告。→ T0.2a `test_hn_front_report`（断言 selector 命中与 http_status）、T0.3a `test_search_to_excel_report`（断言行数下限与字段非空）。
2. **网络瞬时失败**——按附录 D `probe_failed` 语义重试 1 次，仍失败则归因 network 失败退出。→ T0.2a `test_retry_exhausted` / `test_retry_once_then_transient_error`（打桩，不依赖网络）。
3. **礼仪越界**（未声明域、超频次）——必须入口拒绝且不留报告。→ T0.2a `test_etiquette_rejects_undeclared_domain` / `test_rate_limit_enforced`。
4. **Excel 产物损坏或字段错位**——写后必须回读校验。→ T0.3a 回读断言（表头、行数、首列序号）。
5. **Chromium 未安装被误报为站点失败**——定位失败必须抛环境错误并与站点失败区分。→ T0.1a `test_chromium_missing_raises_environment_error`（改 `PLAYWRIGHT_BROWSERS_PATH` 指空目录打桩验证）。

```python
RATE_LIMIT_PER_HOUR = 5          # 每 host 进程内频次上限
REPORT_FIELDS = ("url", "fetched_at", "http_status", "dom_digest",
                 "selector_candidates", "login_flow_shape", "stability",
                 "robots_respected", "captcha_detected")

class EtiquetteViolation(Exception): ...   # 礼仪拒绝（未声明域/超频次/robots 禁止）
class TransientFetchError(Exception): ...  # 重试 1 次后仍失败，归因 network
class CaptchaDetected(Exception): ...      # 命中验证码，不重试（G8）

def reset_rate_limiter() -> None: ...
def _rate_guard(host: str) -> None: ...            # 超限抛 EtiquetteViolation
def _goto_with_retry(page, url: str, attempts: int = 2): ...  # 任意异常重试 1 次，耗尽抛 TransientFetchError
def site_inspect(url: str, declared_domains: list[str], out_path=None) -> dict:
```

`site_inspect` 流程（唯一非平凡实现体，按序）：① host 不等于 declared_domains 中任一项（且非其子域）→ `EtiquetteViolation`；② `_rate_guard`；③ robots：取 `url` 同 host 的 robots.txt（超时 10s）经 `urllib.robotparser` 判定——404/无文件 → `robots_respected=True`；5xx/网络错误 → `None`（记录继续）；禁止 → `EtiquetteViolation`；④ `_goto_with_retry` 访问；⑤ 采集：`http_status`、`fetched_at`（UTC ISO8601）、`dom_digest=sha256(page.content())`、`stability={"response_ms", "load_success", "page_title"}`、`login_flow_shape={"login_link_present": 页面是否含指向 login 的链接}`（不访问登录页，守 G7）、`captcha_detected`=启发式（正文含 `verify you are human` / `iframe[src*="captcha"]` / `input[name^="cf-"]` 任一）；`captcha_detected=True` → 抛 `CaptchaDetected` 且不写 out_path；⑥ `selector_candidates`：对预置候选表逐个探测、命中才收录——HN 前页候选 `story_link`/`story_row`，搜索页候选 `result_item`/`result_title`/`result_meta`（**候选选择器的最终取值以 live DOM 实测为准，实现时确定**）；⑦ `out_path` 给定 → 写 JSON（`ensure_ascii=False, indent=2`）后回读断言 keys == `set(REPORT_FIELDS)`。

`run_search` 流程：① `_goto_with_retry` 打开 `SEARCH_URL_TMPL.format(query=quote(query))`，等待 `SELECTORS["result_item"]`（超时 20s）；② 命中数 < limit → `RuntimeError(f"selector_missing: expected >={limit}, got {n}")`；③ 提取前 limit 行：`position` 1 起整数、`title`/`url` 非空（url 以 http 起）、`points`/`num_comments` 取文本中首个整数（无则 0）；④ `out_json` 写 rows；openpyxl 写 `out_xlsx`（sheet 名 `report`，首行表头 = `ROW_FIELDS`，数字列写 int）；⑤ 回读 `load_workbook` 校验后返回 rows。
