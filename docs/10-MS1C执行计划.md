## 2. Review Focus（计划隐含、任务测试未覆盖的失败面；每行已挂归属测试）

1. **YAML 载荷结构性畸形**——permissions 条目不是 mapping、capabilities 不是列表、runtime 不是 mapping 等非缺字段类畸形的报错路径必须是 `ValidationError`（带字段路径），不是 KeyError/AttributeError 崩溃。→ T1.10 `test_structural_malformed_payload`。
2. **semver 门槛**——version 接受严格 `X.Y.Z` 三段数字；`"1.2"`、`"v1.2.0"`、`"1.2.0-rc.1"` 一律拒绝（锁语义与 patch_window 依赖精确三段）。→ T1.10 `test_semver_gate`。
3. **lint 静态逃逸面**——`rt = runtime` 别名后 `rt.browser.open()` 会逃过家族检查：一层别名必须跟踪；两层以上不追（登记为局限，运行时 PermissionBroker 兜底）。→ T1.11 `test_one_level_alias_tracked`。
4. **violations 输出确定性**——同一目录两次 lint 结果逐字段相等（按 file/line/rule_id 稳定排序），评审抽查可复现。→ T1.11 `test_deterministic_output`。
5. **校验器与 lint 字段语义漂移**——lint 读声明必须走 SDK 同一 loader（`ValidationError → manifest_invalid` 短路），不允许 lint 侧第二份 YAML 解析。→ T1.11 `test_lint_uses_sdk_loader`。

## 3. 具体化裁定（锚未钉死部分；变更走本计划修订登记）

| # | 事项 | 裁定 |
|---|---|---|
| C1 | `block.yaml` 字段集（kind=block） | `schema_version: int == 2`；`kind: "block"`；`name: ^[a-z][a-z0-9_]*$`；`version: 严格 X.Y.Z 三段数字（0-999）`；`title: 非空 str`；`site_change_tier ∈ {standard, medium, high, protected}`；`side_effects: bool`；`capabilities: list[str]`；`permissions: list[{type, value, required: bool}]`；`runtime: {adapter ∈ {python, node, agent}, entry: 非空 str 相对路径, timeout_sec: int ≥ 1}`；`reliability`（**可缺省**；存在时必含 `level ∈ {C0,C1,C2} / pass_rate: float ∈ [0,1] / samples: int ≥ 0 / measured_at: YYYY-MM-DD / environment: 非空 str`）；`ai_description: 非空 str`；`default_response`（仅 side_effects=true 时允许且必填，类型 str 或 mapping）。**未知字段拒绝**。entry 后缀随 adapter：python→`.py`、node→`.js/.mjs`、agent→`.md`（validate_block_dir 校验文件存在） |
| C2 | capabilities / permissions 取值 | capability = M05 §4 家族或 `家族_变体`：`^(browser\|file\|office\|ai\|code\|data\|api\|credential\|confirm\|interact\|probe)(_[a-z0-9_]+)?$`。permission `type ∈ {domain, credential, ai, interact}`（TDD §2.1 示例全集，扩展随 M05 走 minor）；`value` 非空 str，domain 须匹配 `^([a-z0-9-]+\.)+[a-z]{2,}$`，ai ∈ {fast, deep}，interact ∈ {input, login} |
| C3 | `interactions.yaml` | 顶层为 list；每项 `{id: ^[a-z][a-z0-9_]*$ 唯一, type ∈ {input, login, confirm, captcha, review}, title: 非空 str, schema?: mapping, optional?: bool}`；login 类型必含非空 `site`，**site 仅 login 允许**（T1.10 评审登记：锚「login 类型含 site 字段」按排他语义执行）；schema 深度校验归 TestRunner（M07-c），本层只查 mapping |
| C4 | composite_block | v1 SDK **显式不支持**：kind=composite_block 报 `ValidationError("composite_block 不在本 SDK 版本范围")`（不是静默忽略）；支持随 M02 画布卡单独立卡 |
| C5 | 凭证外传检测口径（R8） | 静态一层：`runtime.credential.get("名")`（或其一层别名）结果变量出现在 ①f-string/`%`/`format` 且模板含 url/body 语义词，②`runtime.api.call(...)`/`runtime.browser.*` 调用的 str 实参位 → 违规。全量数据流不做——M05 防御边界声明「防意外不防蓄意」，出口代理运行时兜底 |
| C6 | AST 别名约定 | 跟踪 `X = runtime` / `X = runtime.<家族>` 一层赋值别名；两层以上不追（登记局限） |
| C7 | 幂等键钩子契约（R7） | entry 文件模块级 `def idempotency_key(params) -> str` 存在性（签名/实现正确性归运行时与认证）；side_effects=false 时不要求、也不惩罚多余定义 |
| C8 | R6 动词名单 | `{publish, submit, pay, purchase, checkout, order}`，对全部 `.py` 字符串常量做小写子串匹配；命中且 interactions.yaml 无 `type: confirm` 项 → 违规 |
| C9 | ComponentError 与错误码 | `ComponentError(code, message, detail=None)`；code 必须属于附录 D **组件可抛子集** `{selector_missing, output_schema_violation, component_timeout}`，越集构造抛 `ValueError`。retryable 判定归 DAG 执行器（错误码×副作用矩阵），组件侧不重复编码 |
| C10 | adapter 范围 | lint 对 adapter≠python 的目录返回 `ok=False` + 单条 `adapter_unsupported` error；十规则不运行 |
| C11 | lint 分层与短路 | `lint(block_dir)` 先走 SDK loader：`ValidationError → ok=False, violations=[manifest_invalid]`，十规则跳过。因此 R9（timeout 声明）在目录级只能测**正例**；反例用规则**纯函数级**测试直接构造 spec 覆盖（loader 拦截的重叠语义由 loader 测试负责，lint 是提交门双保险） |
| C12 | lint 输出模型 | `Violation = {rule_id, severity: "error"\|"warning", message, file, line}`；rule_id 固定十语义名：`no_direct_network / dependency_whitelist / require_tests / capability_consistency / interaction_consistency / publish_requires_confirm / side_effect_idempotency_key / credential_exfiltration / timeout_declared / bare_except`（外加编排级 `manifest_invalid / adapter_unsupported`）。排序键 `(file, line, rule_id)`；`ok = 无 error 且 warning 数 ≤ 0`（R10 阈值 v1 钉 0：出现即拒，M09 联调时方可放宽） |
| C13 | R1 网络禁区扩围（T1.11 评审登记） | 锚三模块 requests/urllib/httpx 之外，把 `socket` 与 `http`（覆盖 http.client）一并禁入——积木无理由碰 socket，零误报风险，M05 出口代理之外补静态防线。锚只读不改，本行为计划侧加严裁定 |
