## 2. Review Focus（计划隐含、任务测试未覆盖的失败面；每行已挂归属测试）

1. **快照与步骤错位**——事件定案时页面已翻走，快照存的是下一步的 DOM。→ T1.21b `test_snapshot_taken_at_flush_boundary`（FakeBrowser 在 flush 回调时点返回标记 html，断言快照与步骤对应）。
2. **selector 不稳定**——站点动态 id/class（每次加载变）导致回放必碎。→ T1.21a `test_selector_prefers_stable_attributes`（动态 id 退位到 data-* /文本/结构路径的优先级矩阵）。
3. **偶发抖动误判不一致**——10 次回放中一次网络慢导致 anchor 超时，把确定性流程判成 mismatch。→ T1.22 `test_compare_tolerance_channels`（anchor 迟到→tolerant 通道而非 mismatch；结构相同→similarity 通道）。
4. **脱敏遗漏**——嵌套 JSON 深层字符串、非 JSON body、URL query 值三处漏网，golden 带原始值出本机。→ T1.23 `test_redact_nested_json` / `test_redact_nonjson_body` / `test_redact_url_query` + `test_validate_no_raw_catches_leak`（服务端同规则视角）。
5. **相似度阈值过松**——删掉一半节点的页面仍判相似，mismatch 漏报。→ T1.24 `test_similarity_rejects_structural_change`（构造删半/换 tag 样本，断言低于阈值）。
