### 决策卡 D-M1F.1（Creator Center v1 载体，随本计划生效）

- **登记**：Creator Center 阶段 1 最小版 = forge_server 承载的 web 内部工具——服务端 FlowOrchestrator（creation_sessions 会话状态 + 自动保存）+ `GET /creator` 单文件静态页（vanilla JS 九步向导）。Electron 壳（组 F T1.50）不在 MS-1F 建。
- **理由**：阶段 1 用户 = 平台内部人员，九步全部动作（检索/编排/干跑/认证/提审）本就是服务端能力；web 载体复用 forge_server 全部既有栈，零客户端工程量（跑通优先）。M02-a 四组件职责不缺位：FlowOrchestrator=会话 API、Canvas 基础=线性管线编排（v1 管线，见 C7）、DryRunPanel=干跑端点、CertifyPanel=认证提交/报告端点。
- **边界**：M02 §7 验收 1-3、5、8 逐条生效（验收 4 复合积木/6 脆弱步骤重录/7 阶段 3 埋点不在最小版范围，对应组件 M02-b/c/d 交付）；阶段 3 开放创作者时迁移 Electron（M01）承载，会话模型同构。

## 2. Review Focus（计划隐含、任务测试未覆盖的失败面；每行已挂归属测试）

1. **选站清单站点在认证时段不可达/改版**——产线重试耗尽后整卡卡死，或单站故障拖垮整批认证。→ T1.61 `test_produce_block_retry_then_state_reuse`（3 次失败后仍可续）+ T1.62 `test_drive_continues_on_single_block_failure`（fake runner 一块持续抛错：该块计 env_error——n 计入、pass 不计，**其余块照常达 N**，drive 返回逐块汇总而非中断）【终审修订：原「不达 N」与实现矛盾】。
2. **多积木并发认证错发**——run A 的执行拿了 run B 的 block_ref/golden（router 错路由），live 数据张冠李戴。→ T1.62 `test_router_dispatches_per_run`（两 run 两块各异：各自 live/regression 计数、block_dirs 命中互不串）。
3. **副作用拦截仅 UI 层**——直发保存 API 绕过画布校验，违反 M02 不变量 1 的流程落库。→ T1.64b `test_side_effect_rule_enforced_server_side`（构造 side_effects 块无后置 confirm 的管线，PUT canvas API 直接 422，不落库）。
4. **C0 拦截绕过**——含未认证积木的应用经提审 API 直达提审。→ T1.64b `test_submit_rejects_uncertified_block`（管线含无认证报告的块 → 422 + 响应含转正路径提示文案）。
5. **通过率展示无 N/时间窗或整链混入统计口径**——registry/creator 读侧裸返回比率。→ T1.64a `test_reliability_view_carries_n_and_window`（有样本：N+window+level 标注齐全；无样本："数据不足"字面）+ `test_chain_report_marked_non_statistical`（chain 报告含"非统计值"标注且不进任何统计聚合出口）。

## 7. 风险与处置

| 风险 | 处置 |
|---|---|
| 站点改版/持续不可达（高变更尤甚） | 产线 3 次重试 + C12 换站规程（重录重认证，旧 run 台账登记弃用）；high 块 best_effort 无下限，改版只降通过率不阻塞 verdict |
| 反爬升级（批量真实访问触发封锁） | 礼礼下限已在（5s 间隔/批 20 次/单会话）；选站原则低反爬优先；单站失败不阻塞批次（Review Focus 1）；极端时该块换备选站重走 C12 |
| 多站并发驱动压垮单进程 | router_hook 后调度仍全局 ≥5s 限频（调度器既有），吞吐上限 720 run/h 足够（全库 ~600 run） |
| python 块输出不确定（时间戳等）致 golden 误报 | snapshot 输出契约排除易变字段（模板 main.py 输出仅稳定字段+文件路径）；对拍失败如实 regression_ok=False |
| 48h 窗口跨会话/跨重启 | driver 全幂等 + ms1e_store/state.json + SDD 台账逐段登记（MS-1E 先例） |
| github/jsonplaceholder 限流 | 20 次/48h 远低于匿名限额；失败重试；必要时该场景换 httpbin/npmmirror |
| 通用块 Excel 大结果集 | 块输出只回摘要 + 文件路径，不整表回传（模板契约） |
