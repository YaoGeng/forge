## Review Focus

1. **假覆盖（url_read 空内容 ok=true）**：JS 页 httpx 取到空壳 HTML 却报成功 → 复判时制造假覆盖。测试：T1.73 步骤含「最小内容量断言——text 长度 < 阈值或 title 空 ⇒ ok:false + failure_class: empty_content」用例（离线 monkeypatch httpx 返回空壳）。

3. **既有块 golden 失配**：输出通道改造若把 output 纳入既有块 golden 对拍，旧 expected 快照失配 → 误废有效认证。口径：T1.71 卡内写死「output 仅对新块进 golden 对拍；既有块 golden 比较不含 output」。测试：既有块假 port 回放断言 output 不参与判定。
4. **排除域漏网**：curate 只标注不剔除，法务域条目混入新池。测试：T1.78 含「排除域条目入样即 load_pool 拒绝」用例（构造含博彩域条目的池 → 校验抛错）。
5. **复判重试造假**：runner 对失败样本重试 → 违反恰一次。测试：T1.79 断言每样本 runs 文件恰一份 + judged_at 单值（复用 I1 真实样本复算模式）。

## 风险

- 通用读取块对真实长尾站成功率未知——这正是复判要量的东西；若 url_read 大面积 blocked/empty_content，复判可能再 fail（诚实呈报，不美化）。
- httpx 直读拿不到 JS 渲染内容 → empty_content 如实失败；预期复判池中静态页占比是关键变量（池快照的域外旁证会暴露分布）。
- baidu_home_watch（high 档）加输出后快照基线漂移风险——首跑基线落盘 + changed 判定以基线为锚。
