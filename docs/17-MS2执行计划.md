# MS-2 免费买家闭环 执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 陌生用户可自助完成 注册 → 登录 → 商店浏览（信任字段 v2）→ 免费获取 → 下载运行器 → 本机跑通平台自制应用 → 首跑结果回流统计，全程无人工干预。

**架构：** forge-server 扩展买家域（users/sessions/entitlements/run_reports 四张新表 + 商店读 API + .aapkg 组装分发）；新增 `apps/runner`（Python CLI 运行器，移植 ChainRunner，patchright 有头浏览器执行，PyInstaller 单文件 exe 经 CI 构建后由服务器分发）；商店为 server 同进程渲染的零依赖 HTML 页。**不做收款**——订单/支付/退款冲正/保障金池/结算整体顺延至公开上线后（用户裁定 2026-10-26，见 §0）。

**技术栈：** FastAPI + SQLAlchemy（sqlite 本地 / PG 生产，沿用现状）；hashlib.scrypt（密码，零新依赖）；ed25519（`cryptography`，已在依赖内则用之，否则 hashlib 无签名能力 → 允许入白名单）；patchright（已有）；PyInstaller（仅 CI 构建期）；Web UI 纯 Python 渲染 HTML+CSS，零前端框架。

## Global Constraints（全卡隐含）

- 依赖白名单（A8）：运行时新依赖最多 +`cryptography`（签名）；PyInstaller 只进 CI 构建期，不进运行时
- 密码只存 `hashlib.scrypt` 摘要（salt 16B 随机、n=2^14、dklen=32）；会话 token `secrets.token_urlsafe(32)`；明文密码不得入日志/上报
- API 全部挂 `/api/v1` 前缀；错误返回中文 detail；新表同时过 sqlite 测试与 PG CI（89 用例不得回归）
- 信任字段铁律（M03 §1 不变量 1/2）：任何通过率不带样本量不得渲染数字；不足最小样本显示"数据不足"；页脚声明原文一字不差："运行条件与成功率以信任字段为准；平台审核与认证不构成对运行结果的担保"
- Web UI 遵守原型视觉规范（人民币双色系：橄榄绿主 + 豆沙红点缀 ≤10%，以 `docs/prototypes/` 的 prototype.html 为准），零 JS 依赖起步
- 证据强制（A3）：每卡验收命令输出归档 `spikes/evidence/ms2/`，无证据不合并
- 生产部署沿用 tag 链（docs/16），MS-2 首个上线版本号 **v0.2.0**

## Review Focus（测试必须钉住的五类输入，逐条归卡）

1. **未登录/错 token 访问受保护端点** → 401 + 中文提示，不 500；Web 页 302 跳登录（T2.01/T2.20）
2. **样本不足的通过率** → "数据不足"分支渲染，绝不出现无样本量数字（T2.02/T2.20）
3. **重复获取/重复激活/重复上报** → acquire 幂等返回同一条 entitlement；重复 run-report 不重复计入首跑（T2.03）
4. **.aapkg 篡改与公钥变更** → 摘要或签名不过即拒跑并明确报错；服务器公钥变更（TOFU 冲突）拒绝静默换钥（T2.04/T2.11）
5. **买家机器无 Chromium / 离线** → 首启下载带哈希校验，校验失败拒绝启用；离线时给可读错误与重试指引，不残留半成品（T2.12）
