4) 偏差登记
----------------------------------------------------------------
D1 grep 执行口径：本机 shell 的 grep 是 ZCode ugrep 包装函数，对含 "/" 的模式有解析怪癖
   （printf 'x/admin/y' | grep -F "/admin/" 亦 exit 1，ugrep 7.8.4 实测），故卡面 grep 用
   /usr/bin/grep（GNU）执行；CI/Linux 环境 grep 即 GNU，口径不变。
D2 React 大版本（React19 vs plan §3 树标注 React18）：脚手架 create-vite@9.3.3 出 React 19；
   先按 plan 钉 18.3.1，随即构建被并行车道击穿——portal 车道 @types/react@19 经 pnpm 公共
   提升进入 antd 类型解析链，tsc -b 报 TS2786 ×N（antd 组件类型被解析到
   node_modules/.pnpm/@types+react@19.3.0 与本包 18 冲突，'bigint is not assignable to
   ReactNode'）。工作区统一 React 19.3.1 后根因消除，另按 antd 官方指引加
   @ant-design/v5-patch-for-react-19（防御性；本面板未用 message/Modal 静态法）。
   antd 5.29.3 peer 允许 react>=16.9.0；MUST NOT 清单未钉 React 大版本。曾出现的失败构建
   已在复跑中覆盖（本文件只归档最终绿态 + 根因）。
D3 tsc --noEmit 说明：模板根 tsconfig 为 solution 式（files:[] + references），卡面命令对
   src 实际不做检查、恒 exit 0；真实类型门 = build 脚本内 tsc -b（有效性已由注入式 sanity
   证明，见第 3 节注）。
